# 📚 Інтелектуальний Telegram-бот для вивчення іноземних слів

## 💡 Коротке ознайомлення

Цей проєкт — ваш персональний ШІ-репетитор у Telegram. Він створює адаптивне середовище для вивчення іноземних слів, підлаштовуючись під ваші інтереси та використовуючи алгоритми інтервальних повторень. Бот підтримує мультимовний інтерфейс (українська, англійська, польська)[cite: 1].

**Що під капотом та як це налаштувати (TL;DR):**
*   **🧠 Штучний інтелект (`ai_manager.py`):** Використовує нейромережі для генерації слів, транскрипцій та мнемонічних асоціацій[cite: 1].
*   **🗄️ База даних (`database.py`):** Гнучка система, яка потребує попереднього налаштування. Ви можете підключити PostgreSQL (локально чи в хмарі), а у разі збою бот автоматично перейде на локальний SQLite[cite: 1].
*   **⚙️ Конфігурація (`config.py`):** Всі секретні ключі (токен Telegram, ключі ШІ, доступи до БД) вказуються в одному файлі `.env`[cite: 1].
*   **⚡ Швидкодія (`fuzzy_ext.cpp`):** Для швидкого пошуку слів використовується спеціальне C++ розширення, яке необхідно скомпілювати перед першим запуском через `setup.py`[cite: 1].
*   **🖥️ Адміністрування (`admin.py`):** У комплекті йде окремий десктопний додаток для зручного керування базою та користувачами[cite: 1].

Нижче наведено повний перелік функцій та детальна покрокова інструкція з розгортання проєкту.

## ✨ Основні можливості

*   🔄 **Інтервальні повторення (Spaced Repetition):** Алгоритм динамічно коригує інтервали повторень на основі успішності користувача, забезпечуючи переведення знань з короткочасної у довготривалу пам'ять.
*   🤖 **Гібридний Штучний Інтелект:** Використання генеративних моделей (через `ai_manager.py`) для створення унікального контексту та мнемонічних асоціацій[cite: 1].
*   🎮 **Гейміфікація (Telegram Web App):** Вбудована гра «Word Sprint» з динамічним таймером (`index.html`) для підвищення мотивації[cite: 1].
*   🗄️ **Відмовостійка мультибазова архітектура:** Розумний менеджер баз даних автоматично перемикається між основним сервером та локальною резервною копією.
*   📊 **Десктопна Адмін-панель:** Окремий скрипт `admin.py` для моніторингу активності учнів у реальному часі та управління словниками[cite: 1].
*   🌍 **Мультимовність:** Підтримка локалізації інтерфейсу завдяки файлам конфігурації у папці `locales/` (`en.json`, `pl.json`, `uk.json`)[cite: 1].

## 🛠 Технологічний стек

*   **Back-end:** Python 3.11[cite: 1], Aiogram.
*   **Алгоритми:** C++ (модуль `fuzzy_ext.cpp` для оптимізації нечіткого пошуку)[cite: 1].
*   **Бази даних:** PostgreSQL, SQLite (як резерв)[cite: 1].
*   **ШІ та API:** Google Gemini API, Ollama (опціонально), Pixabay API.
*   **Front-end (Web App):** HTML, CSS, JavaScript (файл `index.html`)[cite: 1].

## 🚀 Детальна інструкція зі встановлення та запуску

### Передумови (Prerequisites)
Перед встановленням переконайтеся, що на вашому пристрої встановлені:
1.  **Python 3.11** (перевірте сумісність через `.python-version`)[cite: 1].
2.  **C++ Compiler** (потрібен для компіляції розширення `fuzzy_ext.cpp`)[cite: 1]. На Windows це Build Tools for Visual Studio, на Linux — `gcc`/`g++` (`sudo apt install build-essential`), на macOS — Xcode Command Line Tools.
3.  **PostgreSQL** (опціонально, якщо плануєте використовувати повноцінну БД).

### Крок 1. Клонування репозиторію та середовище
Завантажте код проєкту та створіть віртуальне середовище:
```bash
git clone <посилання-на-ваш-репозиторій>
cd <назва-папки>

python -m venv venv
# Активація на Windows: venv\Scripts\activate
# Активація на Mac/Linux: source venv/bin/activate
```

### Крок 2. Встановлення залежностей
Встановіть всі необхідні Python-бібліотеки, зазначені у файлі `requirements.txt`[cite: 1]:
```bash
pip install -r requirements.txt
```

### Крок 3. Компіляція C++ розширення (ОБОВ'ЯЗКОВО)
Для роботи алгоритмів пошуку бот використовує C++ модуль. Зберіть його за допомогою скрипта `setup.py`[cite: 1]:
```bash
python setup.py build_ext --inplace
```
*Після успішної компіляції в папці з'явиться готовий до використання файл `.pyd` (наприклад, `fuzzy_ext.cp311-win_amd64.pyd` для Windows) або `.so`[cite: 1].*

### Крок 4. Налаштування змінних оточення (.env)
Модуль `config.py` зчитує налаштування з середовища[cite: 1]. Створіть файл `.env` у кореневій папці проєкту та заповніть його даними:
```ini
# Основні налаштування Telegram
TELEGRAM_BOT_TOKEN=ваш_токен_від_BotFather

# Web App для гри Word Sprint (посилання на index.html)
WEB_APP_URL=https://посилання-на-ваш-сайт/index.html

# Налаштування ШІ та зображень
GEMINI_API_KEYS=ключ1,ключ2,ключ3
PIXABAY_API_KEY=ваш_ключ_від_Pixabay

# Локальний сервер (для Ollama)
SERVER_IP=127.0.0.1

# Налаштування Бази Даних (PostgreSQL)
DB_USER=postgres
DB_PASSWORD=ваш_пароль_від_БД
DB_NAME=word_bot_db
DB_PORT=5432
NEON_URL=postgres://user:pass@host/dbname?sslmode=require
```

### Крок 5. Запуск компонентів

**Запуск Telegram-бота:**
Бот автоматично ініціалізує базу даних, завантажить локалізації з папки `locales/` та спробує підключитися до PostgreSQL[cite: 1].
```bash
python bot.py
```

**Очищення бази (за потреби):**
Для скидання бази даних можна скористатися скриптом `clean_db.py`[cite: 1]:
```bash
python clean_db.py
```

**Запуск Адмін-панелі:**
Для перегляду статистики, керування словниками та користувачами, запустіть файл `admin.py`[cite: 1]:
```bash
python admin.py
```

*   `➕ /add_word` — Додати нове слово до словника.
*   `🎯 /practice` — Запуск режиму тренування та інтервальних повторень.
*   `🌟 /word_of_day` — Отримати випадкове слово відповідного рівня.
*   `🤖 /AI` — Пояснення слова від ШІ (через `ai_helper.py`)[cite: 1].
*   `📊 /stats` — Статистика прогресу навчання.
*   `📝 /all_words` — Вивести весь збережений словник користувача.
