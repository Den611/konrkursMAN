# 📚 Інтелектуальний Telegram-бот для вивчення іноземних слів

[cite_start]Цей проєкт є інноваційним освітнім інструментом, який використовує архітектуру Скінченного Автомата (FSM) та можливості Великих Мовних Моделей (LLM) для створення адаптивної системи навчання[cite: 23]. Бот персоналізує процес вивчення, підлаштовуючись під хобі та тип сприйняття кожного користувача.

## ✨ Основні можливості

* [cite_start]🔄 **Інтервальні повторення (Spaced Repetition):** Алгоритм динамічно коригує інтервали повторень на основі успішності користувача, забезпечуючи переведення знань з короткочасної у довготривалу пам'ять[cite: 25, 128].
* [cite_start]🤖 **Гібридний Штучний Інтелект:** Використання локальних моделей (Ollama) з автоматичним резервним перемиканням на Google Gemini API для генерації унікального контексту, мнемонічних асоціацій та транскрипцій[cite: 26, 89, 274].
* [cite_start]🎮 **Гейміфікація (Telegram Web App):** Вбудована гра «Word Sprint» з динамічним таймером та системою рекордів, що підвищує мотивацію та залученість через мікронавчання[cite: 172, 283].
* 🗄️ **Відмовостійка мультибазова архітектура:** Розумний менеджер баз даних автоматично перемикається між домашнім сервером (PostgreSQL), хмарним сховищем Neon Cloud та локальною базою (SQLite) у разі відсутності з'єднання.
* [cite_start]📊 **Десктопна Адмін-панель:** Окремий додаток на Tkinter для моніторингу активності учнів у реальному часі, управління словниками, створення локальних бекапів та розсилки повідомлень[cite: 190, 219, 220].
* 🧠 **Персоналізація:** Вхідне тестування для визначення психотипу користувача та його захоплень, що дозволяє генерувати приклади вживання слів через призму інтересів учня.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone <посилання-на-ваш-репозиторій>
cd <назва-папки>

```

### 2. Встановлення залежностей

Переконайтеся, що у вас встановлено Python 3.11+.

```bash
pip install -r requirements.txt

```

### 3. Налаштування змінних оточення (.env)

Створіть файл `.env` у кореневій папці проєкту та додайте необхідні ключі налаштувань:

```ini
# Основні налаштування Telegram
TELEGRAM_BOT_TOKEN=ваш_токен_від_BotFather
WEB_APP_URL=https://посилання-на-ваш-сайт/index.html

# Налаштування ШІ та API
GEMINI_API_KEYS=ключ1,ключ2,ключ3
PIXABAY_API_KEY=ваш_ключ_від_Pixabay

# Налаштування Баз Даних (PostgreSQL)
SERVER_IP=127.0.0.1
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_NAME=word_bot_db
DB_PORT=5432

# Резервна хмарна база
NEON_URL=postgres://user:pass@host/dbname?sslmode=require

```

### 4. Запуск Telegram-бота

Бот автоматично ініціалізує базу даних та спробує підключитися до PostgreSQL. Якщо сервери недоступні, він перейде у режим роботи з локальною SQLite (`backup_words.db`).

```bash
python bot.py

```

### 5. Запуск Адмін-панелі

Для перегляду статистики, відгуків та створення локальних бекапів запустіть графічний додаток:

```bash
python admin.py

```

## 📚 Доступні команди бота

* `➕ /add_word` — Додати нове слово (з автоперекладом та генерацією асоціації).
* `🎯 /practice` — Запуск режиму інтервальних повторень (Spaced Repetition).
* `🌟 /word_of_day` — Згенерувати нове випадкове слово відповідного рівня.
* `🤖 /AI` — Запитати у ШІ пояснення будь-якого слова на основі ваших хобі.
* `📊 /stats` — Переглянути свій рівень, досвід (XP) та рекорд у грі.
* `🏆 /top` — Таблиця лідерів (рекорди з Web App гри).
* `📝 /all_words` — Вивести весь збережений словник.
* `📥 /import_words` — Масове завантаження слів з файлу `.csv` або `.txt`.
* `💬 /feedback` — Надіслати відгук чи пропозицію розробнику.
